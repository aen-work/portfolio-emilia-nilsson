# Emilia Nilsson – Frontend Developer Portfolio

My personal portfolio, built with plain HTML, CSS and vanilla JavaScript (no frameworks or libraries). It shows my projects, skills and a bit about me.

## Features

- **Dark and light theme** – toggle in the menu, saved in `localStorage` and defaults to the system preference
- **Project filter** – filter projects by JavaScript, CSS, Team or AI
- **Interactive hero** – a spotlight that follows the mouse and animated counters
- **3D tilt effect** on project cards
- **Sticky navigation** with smooth scrolling between sections
- **Copy email button** using the Clipboard API
- **Responsive layout** using CSS Grid and Flexbox, with `prefers-reduced-motion` support

## Built with

- HTML5
- CSS3 (custom properties, Grid, Flexbox, `backdrop-filter`, animations)
- JavaScript (ES6+, DOM manipulation, event handling, `localStorage`, Clipboard API)
- [Quicksand](https://fonts.google.com/specimen/Quicksand) font from Google Fonts

## Project structure


## Run locally

No build step or installation is needed.

1. Clone or download this repository
2. Open `index.html` in your browser

Optionally, use a local server such as the VS Code extension *Live Server*.
